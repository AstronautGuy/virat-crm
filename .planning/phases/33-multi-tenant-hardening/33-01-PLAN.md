# Phase 33 Gap Closure Plan

## Goal
Fix the infinite render loop in `useLocationBreadcrumbs` that causes `ERR_INSUFFICIENT_RESOURCES` and blocks the app from functioning, which in turn blocks testing the multi-tenant hardening.

## Proposed Changes

### `src/hooks/use-location-breadcrumbs.ts`
- **Issue**: `logBreadcrumb` is a mutation object that changes reference on every render because `mutate` updates the query state. Since `logBreadcrumb` is in the dependency array of `captureLocation`, it causes `captureLocation` to be recreated constantly, which triggers the `useEffect` to clear and reset the interval, calling `captureLocation()` again in an infinite loop.
- **Fix**: Destructure the `mutate` function directly from the `useMutation` hook. React Query guarantees the `mutate` function has a stable identity.
  - Change `const logBreadcrumb = (api.location.logBreadcrumb as any).useMutation();` to `const { mutate: logBreadcrumbMutate } = (api.location.logBreadcrumb as any).useMutation();`
  - Update all `logBreadcrumb.mutate(...)` calls to `logBreadcrumbMutate(...)`.
  - Update the dependency array of `captureLocation` to depend on `logBreadcrumbMutate` instead of `logBreadcrumb`.

## Verification Plan
1. Start the development server (`pnpm run dev`).
2. Load the web dashboard as an Employee/Manager.
3. Observe the network tab; there should be no infinite loop of `location.logBreadcrumb` requests.
4. Verify that branch isolation tests from Phase 33 can now be conducted normally.
