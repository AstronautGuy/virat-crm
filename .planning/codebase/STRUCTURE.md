# STRUCTURE.md

## Directory Layout
- `src/app/`: Next.js App Router pages, layouts, and API routes.
- `src/components/`: Reusable UI components (often generated by shadcn/ui).
- `src/hooks/`: Custom React hooks.
- `src/lib/`: Shared utilities, helper functions, and third-party library wrappers.
- `src/server/`: Backend specific code.
  - `src/server/api/`: tRPC setup and routers.
  - `src/server/db/`: Drizzle ORM schema, migrations, and instance.
- `src/styles/`: Global CSS styles (Tailwind imports).
- `src/trpc/`: tRPC client setup for React/Next.js.

## Key Locations
- `src/env.js`: Environment variable validation and typings.
- `drizzle.config.ts`: Configuration for Drizzle Kit (migrations).
- `next.config.js`: Next.js framework configuration.

## Naming Conventions
- React Components: PascalCase (e.g., `Button.tsx`).
- Utilities/Hooks: camelCase (e.g., `useAuth.ts`, `formatDate.ts`).
- Routing: lower-case directory names with Next.js standard files (`page.tsx`, `layout.tsx`).
